# Blog Analytics Dashboard

Source issue: https://github.com/LaceyPsych/laceypsych.github.io/issues/100

This dashboard tracks public performance and editorial learning across published
Generative Systems Psychology posts.

Analytics should guide presentation, sequencing, accessibility, and distribution.
Analytics should not distort Generative Systems Psychology.

If popularity and theoretical integrity conflict, theoretical integrity wins.

## Update Protocol

Update the individual blog issue first, then copy summary metrics here.

Use `docs/editorial-style-guide.md` for the style standard. A post should not be
marked editorially complete unless it preserves GSP fidelity, accountability,
public safety, and the generated-output pathway relevant to the article.

Suggested cadence:

- 24 hours after publication;
- 7 days after publication;
- 30 days after publication;
- monthly rollup by arc;
- whenever a meaningful reader response changes future editorial planning.
